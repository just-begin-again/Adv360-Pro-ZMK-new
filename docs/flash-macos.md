# Обновление Advantage360 Pro с Mac

Для обычного обновления подключите обе половины кабелями USB с передачей данных. Левая половина должна быть включена первой, правая должна подключиться к ней по Bluetooth. В этой раскладке уже есть штатные команды Kinesis. Удерживайте физическую клавишу Mod и нажмите Hotkey 1 для левой половины или Hotkey 3 для правой. У `Mod` крайнее положение во внутреннем верхнем ряду справа, рядом с `6`. Клавиша ① находится у внутреннего края слева рядом с `T`, клавиша ③ — под `Mod` рядом с `Y`. Загружайте UF2 по очереди, сначала слева. [Руководство Kinesis, раздел 5.9](https://kinesis-ergo.com/wp-content/uploads/Advantage360-ZMK-KB360-PRO-Users-Manual-v12-11-23.pdf) · [Быстрый старт, стр. 8](https://kinesis-ergo.com/wp-content/uploads/Advantage360-Professional-QSG_2-27-23.pdf)

- **Mod** находится на правой половине, в верхнем ряду у внутреннего края, рядом с `6`.
- **①** находится у внутреннего края левой половины, рядом с физической `T` в QWERTY.
- **③** находится прямо под Mod, рядом с физической `Y` в QWERTY. [Схема Kinesis, стр. 7](https://kinesis-ergo.com/wp-content/uploads/Advantage360-ZMK-KB360-PRO-Users-Manual-v12-11-23.pdf#page=7)

Возьмите пару UF2 из одного артефакта GitHub Actions или одной локальной сборки. Для текущей сборки из этой ветки команды выглядят так.

```sh
python3 bin/flash_adv360.py --dry-run firmware/adv360-legacy-symbols-left.uf2 firmware/adv360-legacy-symbols-right.uf2
python3 bin/flash_adv360.py firmware/adv360-legacy-symbols-left.uf2 firmware/adv360-legacy-symbols-right.uf2
```

1. На экране появится приглашение `[left]`. Удерживайте Mod и нажмите Hotkey 1. Помощник найдёт загрузочный диск, проверит его и запишет левый UF2.
2. Когда диск исчезнет, дождитесь обычной индикации слева и восстановления связи справа. При приглашении `[right]` удерживайте Mod и нажмите Hotkey 3. Помощник запишет правый UF2.
3. Дождитесь завершения синего мигания. Удержите Mod и проверьте зелёный индикатор слоя на обеих половинах, затем проверьте нажатия слева и справа. Если справа три красных индикатора, перезапустите обе половины, включая левую первой. Если питание идёт по USB, для полного выключения временно выньте кабель и выключите батарею. [Поддержка Kinesis](https://kinesis-ergo.com/support/kb360pro/)

Помощник требует Python 3.9 или новее. `--dry-run` проверяет структуру UF2, область записи и имя USB-устройства внутри каждого образа. Он печатает SHA-256 файлов. Общий префикс имени обнаруживает случайный выбор разных сборок. Происхождение пары подтверждайте по артефакту сборки или его опубликованным хешам. При записи помощник ищет один внешний USB-том `Adv360 Pro` или `ADV360PRO` с `INFO_UF2.TXT`. Если загрузчик показывает читаемый `CURRENT.UF2`, помощник сверяет сторону по USB-дескриптору установленной прошивки. `--list` показывает открытые загрузочные тома и распознанную сторону, если она доступна. [Спецификация UF2](https://github.com/microsoft/uf2#files-exposed-by-bootloaders) · [Имена устройств в конфиге](../config/boards/arm/adv360/Kconfig.defconfig)

- Если одновременно открылись два загрузочных диска, выведите обе половины из загрузчика, восстановите связь и запустите команду заново.
- Если `--list` видит том как `unidentified`, для записи можно указать `--allow-unidentified`. В этом режиме подключайте по USB только обновляемую половину, а вторую держите включённой от батареи. Проверьте метку стороны на клавиатуре и нажмите указанную комбинацию. При явном несовпадении стороны помощник прекращает работу и с этим флагом.
- Если macOS вернула ошибку синхронизации при исчезновении USB-тома, помощник остановится. Дождитесь нормальной индикации, снова откройте загрузчик этой половины и передайте ту же пару в режиме `--verify-installed`. Если загрузчик даёт прочитать `CURRENT.UF2`, помощник сравнит установленные байты с образом. Затем закройте загрузчик полным выключением и включением половины. [Пошаговая инструкция Kinesis](https://kinesis-ergo.com/wp-content/uploads/Advantage360-Professional-Firmware-Update-Instructions-11.22.23-KB360-PRO-GBR.pdf)
- Если левая половина уже обновилась, а правая ещё нет, повторите команду с `--right-only` и той же парой файлов. Если правая не подключается после включения слева направо, кнопка Reset на правой половине позволяет открыть диск напрямую. Для её использования запустите помощник до нажатия Reset, чтобы он увидел появление единственного диска для нужной стороны. [Пошаговая инструкция Kinesis](https://kinesis-ergo.com/wp-content/uploads/Advantage360-Professional-Firmware-Update-Instructions-11.22.23-KB360-PRO-GBR.pdf)
- Для отката используйте ту же процедуру с парой `hardware-recovery-left.uf2` и `hardware-recovery-right.uf2`. При проблемах совместимости между версиями проверьте инструкции Kinesis к версии, на которую переходите. [Хеши файлов для восстановления](unified-layout.md#build-flash-and-rollback) · [Файлы и инструкции Kinesis](https://kinesis-ergo.com/support/kb360pro/#firmware-updates)

Два USB-кабеля дают Mac доступ к дискам после входа в загрузчик. Способ перевести обе половины в этот режим одной командой с Mac в документации Kinesis и текущей прошивке не найден. При рабочей связи хватает двух комбинаций Mod. Если половины не соединяются или прошивка не отвечает, нужен физический Reset на соответствующей стороне. Clique позволяет менять поддерживаемые настройки раскладки по USB, полная замена прошивки выполняется через загрузчик. [Документация Clique и обновления](https://kinesis-ergo.com/support/kb360pro/)

Если после обновления символы работают по USB, а по Bluetooth пропали, сначала отключите и снова подключите Adv360 Pro в настройках Bluetooth macOS. На этом Mac это обновило старый HID-дескриптор без сброса пары. [Шаги диагностики Bluetooth](unified-layout.md#symbols-over-bluetooth)
